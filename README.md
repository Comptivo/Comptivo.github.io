# Comptivo — Site promotionnel multilingue

Cette version du site a été préparée comme une page promotionnelle et de présentation pour GitHub Pages.

## Contenu
- Logo fourni par le client intégré dans le site
- Capture d'écran intégrée avec **données fictives**
- Version **trilingue** : Français / English / العربية
- Section présentation
- Section fonctionnalités
- Section interface
- Section contact

## Publication sur GitHub Pages
1. Créez un dépôt GitHub.
2. Envoyez tous les fichiers en gardant le dossier `assets`.
3. Ouvrez `Settings > Pages`.
4. Choisissez `Deploy from a branch`.
5. Sélectionnez `main` et `/ (root)`.
6. Enregistrez.

Le site sera ensuite publié automatiquement.
